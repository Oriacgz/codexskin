The approved codexskin logo was generated with Canva (asset MAHW8NLCkTk).

`logo-source.jpg` is the 200 × 200 preview available through the Canva connector.
`codexskin.ico` contains classic 32-bit Windows icon frames at 16, 24, 32, 48,
64, 128, and 200 pixels. `src/core/brand-assets.js` embeds these assets so the
standalone executable does not require an external assets folder.

Replace the source with the original 1264 × 1264 export before producing larger
marketing artwork. The current icon frames never upscale the available source.
